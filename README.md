# IPL Data Analysis
## Project Overview
This project analyzes IPL matches and ball-by-ball data to uncover patterns related to player performance,
team performance, venues, toss decisions, and match outcomes.

## Tools Used
* Python
* SQL
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Key Analyses
* Season-wise Runs Trend
* Top Run Scorers
* Top Wicket Takers
* Death Over Analysis
* Toss Impact Analysis
* Stadium Analysis
* Playoff Performance Analysis
8 Dismissal Analysis
